## Notas de implementação

- Tokens só em `:root` (o tema é sempre escuro; sem variante clara) + regra `body { background: var(--vl-bg); color: var(--vl-text); font-family: var(--vl-font-sans); margin: 0 }`
- Em `main.ts`: `import './styles/tokens.css'`; `app.use(PrimeVue, { theme: { preset: Vilarejo, options: { darkModeSelector: '.vl-escuro' } }, ... })` mantendo a licença `VITE_PRIMEUI_LICENSE`; `document.documentElement.classList.add('vl-escuro')` antes do `mount`.
- Usar skill `primevue:primevue-theming-customization` para validar sintaxe de `definePreset`/`darkModeSelector`
- Preset: `definePreset(Aura, {...})` de `@primeuix/themes`; `semantic.primary` = escala âmbar com 500 = `#e8b55a`; `semantic.colorScheme.dark.surface` 0..950 quentes (950 `#1a1714`, 900 `#211d19`, 800 `#27231f`, 700 `#332e29`, 600 `#3d3731`, 0 `#ffffff`); `primary.contrastColor` `#1d1a17`; `highlight` com fundo âmbar 12–16%.
- Manter todas as linhas de assets e configurações de build em `index.html` e template do backend

## Critérios de aceite

- Tokens CSS em `:root`
