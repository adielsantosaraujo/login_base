## Notas de implementação

- Todos os estilos devem usar **apenas tokens CSS** (variáveis `--vl-*`), sem hex/rgb direto
- Cada componente tem seu `.spec.ts` testando estados e acessibilidade
- Componentes devem ser composáveis e reutilizáveis
- Usar PrimeIcons onde necessário (`pi pi-spin pi-spinner` para carregamento)

## Critérios de aceite

- Specs cobrindo todos os estados e acessibilidade
- Só tokens nos estilos (nenhum hex/rgb)
- Componentes montam e interagem corretamente
- Build sem erros
