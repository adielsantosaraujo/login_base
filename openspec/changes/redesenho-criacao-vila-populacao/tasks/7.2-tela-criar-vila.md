## Notas de implementação

- Tiles são `<button>` com `aria-pressed`, `aria-disabled`, `aria-label` detalhado ("Região 06 · Urbana · Comércio 47, …")
- `mouseleave` e `blur` limpam hover
- Foco visual = hover
- Toast de erro com mensagem do backend
- Layout responsivo: painel desce abaixo do mapa em tela estreita
- Usar tokens CSS para cores, espaçamento, tipografia
- Textos: 'Gerar novo mapa' (com carregamento) e 'Mapa nº <rodada>'; botão 'Criar vila' só com seleção válida, senão 'Selecione 3 regiões válidas' desabilitado; checklist '3 regiões n/3', 'Vizinhas entre si', 'Ao menos 1 Urbana'; botão 'Limpar'. Usar `CabecalhoJogo`/`BotaoCta`/`ChecklistItem`/`BarraValor`/`AvisoToast` da task 6.6.

## Critérios de aceite
