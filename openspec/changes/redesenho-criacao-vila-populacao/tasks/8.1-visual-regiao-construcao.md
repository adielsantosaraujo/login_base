- Remover todos hex/rgb diretos nos `<style>`
- Usar apenas variáveis CSS de tokens
- Para transparências, usar variáveis com opacity derivadas dos tokens
- Títulos usam `--vl-font-display`
- Números/monospace usam `--vl-font-mono`

- Specs verdes
- Build verde
