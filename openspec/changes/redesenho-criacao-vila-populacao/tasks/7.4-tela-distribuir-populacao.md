## Notas de implementação

- Indicador de etapas: "01 Regiões ✓" é texto (etapa concluída), não link
- Usar tokens CSS para cores, espaçamento, tipografia
- Layout responsivo
- 'Redistribuir pelo plano' desabilitado com `title="O plano precisa somar 16"` quando o plano ≠ 16; botão 'Confirmar população' só com mínimos atendidos e líder escolhido, senão 'Ajuste os mínimos'; pendências aparecem como aviso ('Pontos pendentes N') e não bloqueiam; '+' desabilitado no total 20/10 e '−' em 0; bônus R3 em cada profissão com a explicação no `title`.

## Critérios de aceite

- Todos os cenários do spec passam
- Sem chamadas HTTP durante edição (apenas na confirmação)
- Acessibilidade: labels, aria-*, navegação por teclado
- Sem hex/rgb nos estilos (apenas tokens)
- Build e testes verdes
