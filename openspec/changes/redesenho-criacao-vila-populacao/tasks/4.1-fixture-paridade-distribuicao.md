## Notas de implementação

**Estrutura do JSON:**

```json
{
  "geradoDe": "docs/designe/handoff/referencia/distribuicao-populacao.js",
  "pessoas": {
    "CONSTRUTOR": {
      "caracteristicas": {"VIT": 3, "FOR": 5, "VEL": 4, "INT": 8, "CAR": 0},
      "profissoes": {12 chaves de profissões com valores}
    },
    ...
  },
  "familias": [
    {
      "sobrenome": "Oliveira",
      "cidadaos": [
        {"nome": "Marcos", "sexo": "M", "idadeAnos": 40, "papel": "PAI"},
        ...4 cidadãos por família
      ]
    },
    ...4 famílias (Oliveira, Lima, Almeida, Pereira)
  ],
  "casos": [
    {
      "nome": "plano-padrao",
      "plano": {COMERCIANTE: 1, CONSTRUTOR: 2, ...},
      "resultado": [[{caracteristicas, profissoes, principal} x4] x4],
      "familiaLiderSugerida": 0
    },
    {"nome": "plano-cacador-costureiro", "plano": {"COMERCIANTE":1,"CONSTRUTOR":2,"CARREGADOR":2,"MADEIREIRO":2,"MINEIRO":2,"AGRICULTOR":2,"FAZENDEIRO":1,"COZINHEIRO":1,"GUERREIRO":1,"FERREIRO":0,"COSTUREIRO":1,"CACADOR":1}, "resultado": [...], "familiaLiderSugerida": <n>},
    {"nome": "plano-construtores-carregadores", "plano": {"COMERCIANTE":1,"CONSTRUTOR":4,"CARREGADOR":4,"MADEIREIRO":1,"MINEIRO":1,"AGRICULTOR":1,"FAZENDEIRO":1,"COZINHEIRO":1,"GUERREIRO":1,"FERREIRO":1,"COSTUREIRO":0,"CACADOR":0}, "resultado": [...], "familiaLiderSugerida": <n>}
  ]
}
```

- Converter chaves `vit..car` para MAIÚSCULAS em caracteristicas
- Profissões: usar as 12 chaves do enum Profissao (ex.: COMERCIANTE, CONSTRUTOR, etc.)
- Planos somam 16 cidadãos cada (4 famílias × 4 cidadãos)
- Script Node (`gerar-fixture-paridade.cjs`): faz `require` do JS de referência e grava o JSON
- Reutilizar nomes de R2 do handoff: Oliveira, Lima, Almeida, Pereira
- Os nomes, sexos, idades e papéis das 16 pessoas são os da R2 de `/docs/designe/handoff/regras/regras-populacao-v1.md`. O JS de referência exporta via `module.exports` (linha ~160): `require('../../docs/designe/handoff/referencia/distribuicao-populacao.js')` a partir de `frontend/scripts/`. As chaves `vit..car` do JS viram MAIÚSCULAS. A tabela `pessoas` tem de bater com a tabela de vetores do D7 (12 linhas).

## Critérios de aceite

- JSON válido e parseável
- Tabela `pessoas` com 12 profissões, cada com 5 características (VIT, FOR, VEL, INT, CAR)
- `casos[0]` (plano padrão): pai da 1ª família (Oliveira) = COMERCIANTE com CAR=13
- `caracteristicas.VIT` = 1, `FOR` = 1, `VEL` = 5, `INT` = 0, `CAR` = 13 para o pai
- Rodar o script de novo gera arquivo idêntico (fixture congelada)
