## Notas de implementação

**QuartelView.vue:**

Componente deve exibir:

1. **Cabeçalho:** "Quartel" com nível exibido

2. **Formulário de treino:**
   - Select "Tipo de tropa": SOLDADO, ARQUEIRO, LANCEIRO (valores de `TipoTropa`)
   - Select "Nível da arma": 1–5 (agrupado por modelo = modelo exigido pelo tipo)
   - Select "Armadura": opções agrupadas por modelo e nível, ex. "Couro N1 (4)" indicando quantidade disponível
   - InputNumber "Quantidade": min 1, max = dica calculada (número dinâmico)
   - Botão "Máx.": preenche quantidade com o máximo calculável
   - Botão "Treinar": POST `/api/jogo/quartel/ordens` com `TreinarRequest`

3. **Feedback de erros:**
   - Se erro 422: exibir código (CAPACIDADE_EXERCITO, ITEM_INDISPONIVEL, RECURSOS_INSUFICIENTES) em mensagem amigável
   - Se erro 400: exibir "Quantidade inválida"

4. **Progresso:**
   - Exibir ordem TREINO em andamento (se houver): "Treinando N unidades — tempo restante 3m 45s"
   - Calcular `unidadesAtivas` = soma `quantidade` de ordens TREINO em andamento

5. **Lista de unidades:**
   - Tabela ou lista com colunas: Nome, Tipo, Status, Arma, Armadura
   - Coluna "Nome" exibe `unidade.nomeExibicao` (ex.: "Ana Silva (2)"; não montar o sufixo no cliente) e é clicável: `router.push(`/quartel/unidades/${unidade.id}`)`
   - Atualizar lista após conclusão de ordem (polling ou WebSocket no futuro)

**Cálculo de máximo (frontend é só exibição, regra fica no backend):**
- Dica: `min(armasDisponiveis, armadurasDisponiveis, floor(comida / comidaPorTreino), capacidadeLivre)`
- Backend valida estritamente; se cliente enviar acima do máximo, recebe 422

**Estilo/Componentes:**
- Usar componentes PrimeVue conforme projeto (Dropdown, InputNumber, Button, DataTable, ProgressBar)
- Manter consistência com componentes existentes (ForjaView, etc)

## Critérios de aceite

- Formulário exibe selects de tipo, nível arma, modelo/nível armadura
- Campo quantidade com min 1
- Botão "Máx." calcula e preenche
- POST envia novo contrato (armaNivel, armaduraModelo, armaduraNivel, quantidade)
- Erros 422 exibem mensagens apropriadas
- Coluna Nome mostra `nomeExibicao`
- Coluna "Nome" é clicável e navega a `/quartel/unidades/{id}`
- Componente exibe progresso de treino em andamento
- QuartelView.vue compila sem erros (verificado com `cd frontend && npm run build`)
