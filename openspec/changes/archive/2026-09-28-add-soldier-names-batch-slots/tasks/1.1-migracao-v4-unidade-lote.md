## Objetivo

Implementar a migração V4 do banco de dados para adicionar colunas `nome` e `sobrenome` à tabela `jogo_unidades`, adicionar suporte a `jogo_itens.ordem_id` para vincular itens às ordens, remover `jogo_ordens.arma_item_id` e `armadura_item_id`, e atualizar as entidades Java correspondentes para refletir a nova estrutura de dados. Também cria a coluna `ordinal_nome` em `jogo_unidades` e a tabela `jogo_contadores_nome` (contador histórico de nomes por vila), com as entidades `ContadorNome`/`ContadorNomeRepository` e o método `Unidade#nomeExibicao()`.

## Notas de implementação

**Migração V4 (Flyway):**
- Arquivo: `src/main/resources/db/migration/V4__unidade_nome_e_lote_treino.sql`
- Adicionar colunas: `ALTER TABLE jogo_unidades ADD COLUMN nome VARCHAR(60), ADD COLUMN sobrenome VARCHAR(60);`
- Backfill determinístico usando os 10 primeiros nomes e sobrenomes:
  ```sql
  UPDATE jogo_unidades 
  SET nome = (array['Ana', 'Maria', 'Francisca', 'Antônia', 'Adriana', 'Juliana', 'Márcia', 'Fernanda', 'Patrícia', 'Aline'])[1 + id % 10],
      sobrenome = (array['Silva', 'Santos', 'Oliveira', 'Souza', 'Rodrigues', 'Ferreira', 'Alves', 'Pereira', 'Lima', 'Gomes'])[1 + (id / 10) % 10];
  ```
- `ALTER TABLE jogo_unidades ALTER COLUMN nome SET NOT NULL, ALTER COLUMN sobrenome SET NOT NULL;`
- `ALTER TABLE jogo_itens ADD COLUMN ordem_id BIGINT;`
- `ALTER TABLE jogo_itens ADD CONSTRAINT fk_jogo_itens_ordem FOREIGN KEY (ordem_id) REFERENCES jogo_ordens(id);`
- `CREATE INDEX ix_jogo_itens_ordem ON jogo_itens(ordem_id);`
- Migrar ordens TREINO:
  ```sql
  UPDATE jogo_itens i SET ordem_id = o.id 
  FROM jogo_ordens o 
  WHERE o.categoria = 'TREINO' AND i.id IN (o.arma_item_id, o.armadura_item_id);
  ```
- Remover colunas e FK de `jogo_ordens`:
  ```sql
  ALTER TABLE jogo_ordens DROP CONSTRAINT fk_jogo_ordens_arma_item, DROP CONSTRAINT fk_jogo_ordens_armadura_item;
  ALTER TABLE jogo_ordens DROP COLUMN arma_item_id, DROP COLUMN armadura_item_id;
  ```

- Ordinal e contador (depois do backfill de nome/sobrenome):
  ```sql
  ALTER TABLE jogo_unidades ADD COLUMN ordinal_nome INT;
  UPDATE jogo_unidades u SET ordinal_nome = r.ordinal
  FROM (SELECT id, row_number() OVER (PARTITION BY vila_id, nome, sobrenome ORDER BY id) AS ordinal FROM jogo_unidades) r
  WHERE r.id = u.id;
  ALTER TABLE jogo_unidades ALTER COLUMN ordinal_nome SET NOT NULL,
    ADD CONSTRAINT ck_jogo_unidades_ordinal_nome CHECK (ordinal_nome >= 1),
    ADD CONSTRAINT uk_jogo_unidades_nome_ordinal UNIQUE (vila_id, nome, sobrenome, ordinal_nome);
  CREATE TABLE jogo_contadores_nome (
    id bigint generated always as identity,
    vila_id bigint not null,
    nome varchar(60) not null,
    sobrenome varchar(60) not null,
    ultimo_ordinal int not null,
    criado_em timestamptz not null, criado_por varchar(150) not null,
    alterado_em timestamptz not null, alterado_por varchar(150) not null,
    constraint pk_jogo_contadores_nome primary key (id),
    constraint fk_jogo_contadores_nome_vila foreign key (vila_id) references jogo_vilas (id),
    constraint uk_jogo_contadores_nome unique (vila_id, nome, sobrenome),
    constraint ck_jogo_contadores_nome_ultimo check (ultimo_ordinal >= 1)
  );
  INSERT INTO jogo_contadores_nome (vila_id, nome, sobrenome, ultimo_ordinal, criado_em, criado_por, alterado_em, alterado_por)
  SELECT vila_id, nome, sobrenome, count(*), now(), 'sistema', now(), 'sistema'
  FROM jogo_unidades GROUP BY vila_id, nome, sobrenome;
  ```
