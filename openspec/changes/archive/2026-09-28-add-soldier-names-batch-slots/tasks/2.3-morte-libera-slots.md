# Task 2.3 — Morte libera slots

**Índice:** [tasks.md](../tasks.md) · **Depende de:** 1.3, 2.1 · **Paralela com:** —

## Objetivo

Atualizar `MasmorraService` para iterar sobre os 9 slots de equipamento (enum `SlotEquipamento`) ao processar a morte de uma unidade, destruindo os itens ocupados (na prática, arma e armadura atuais) e marcando os slots vazios corretamente. Os itens destruídos são os equipados no momento da morte (já refletindo trocas); itens retirados antes por troca estão `DISPONIVEL` e não são afetados.

## Notas de implementação

**MasmorraService.atualizarEsquadraoAoFinal (ou método equivalente):**

Ao processar morte de uma unidade:

```java
for (SlotEquipamento slot : SlotEquipamento.values()) {
  Long itemId = null;
  
  if (slot == SlotEquipamento.ARMA) {
    itemId = unidade.getArmaItemId();
  } else if (slot == SlotEquipamento.ARMADURA) {
    itemId = unidade.getArmaduraItemId();
  }
  // demais slots: itemId fica null
  
  if (itemId != null) {
    itemRepository.deleteById(itemId);
  }
}
```

A iteração é preparatória para o futuro, quando slots adicionais terão dados persistidos. Por enquanto, apenas ARMA e ARMADURA possuem dados.

**MasmorraServiceTest.java:**
- Adicionar teste que valida iteração e destruição
- Validar que unidade morta → itens arma + armadura são apagados
- Validar que não há erro ao iterar slots futuros (nulos)

## Critérios de aceite

- `MasmorraService` itera sobre `SlotEquipamento.values()` ao processar morte
- Itens ocupados (arma, armadura) são destruídos
- Slots vazios (futuros) não causam erro
- Testes cobrem morte com destruição correta
