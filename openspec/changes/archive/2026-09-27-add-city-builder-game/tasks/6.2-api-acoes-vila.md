## Notas de implementação

### Request records com `@Valid`
- `PlantarRequest(Cultivo cultivo)` — enum inválido → 400.
- `ForjarRequest(ModeloItem modelo, int nivel, int quantidade)` — validar `nivel` 1–5, `quantidade` 1–5 → 400 em `@Valid`.
- `TreinarRequest(TipoTropa tipo, long armaId, long armaduraId)` — validar armaId/armaduraId > 0 → 400.
- `MelhorariaPredioRequest` — pode ser vazio (request body não obrigatório).

### `AcoesVilaController`
```java
@RestController
@RequestMapping("/api/jogo")
@Transactional
public class AcoesVilaController {
  @PostMapping("/predios/{tipo}/melhorar")
  public ResponseEntity<VilaDto> melhorar(
      @PathVariable TipoPredio tipo,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    construcaoService.melhorar(usuarioId, tipo);
    EstadoVila estado = vilaService.consultar(usuarioId);
    return ResponseEntity.ok(jogoMapper.toVilaDto(estado, clock));
  }

  @PostMapping("/canteiros/{posicao}/plantar")
  public ResponseEntity<VilaDto> plantar(
      @PathVariable int posicao,
      @Valid @RequestBody PlantarRequest req,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    fazendaService.plantar(usuarioId, posicao, req.cultivo());
    EstadoVila estado = vilaService.consultar(usuarioId);
    return ResponseEntity.ok(jogoMapper.toVilaDto(estado, clock));
  }

  @PostMapping("/forja/ordens")
  public ResponseEntity<VilaDto> forjar(
      @Valid @RequestBody ForjarRequest req,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    forjaService.forjar(usuarioId, req.modelo(), req.nivel(), req.quantidade());
    EstadoVila estado = vilaService.consultar(usuarioId);
    return ResponseEntity.ok(jogoMapper.toVilaDto(estado, clock));
  }

  @PostMapping("/quartel/ordens")
  public ResponseEntity<VilaDto> treinar(
      @Valid @RequestBody TreinarRequest req,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    quartelService.treinar(usuarioId, req.tipo(), req.armaId(), req.armaduraId());
    EstadoVila estado = vilaService.consultar(usuarioId);
    return ResponseEntity.ok(jogoMapper.toVilaDto(estado, clock));
  }
}
```
- Todas as rotas retornam 200 `VilaDto` (estado atualizado pós-ação).
- Erro 422/409 levantado pelo serviço é capturado por `ErroApiHandler`.

### Validação de request body
- `@Valid @RequestBody` + anotações `@NotNull`, `@Min`, `@Max` nas classes request.
- Validação falha → `MethodArgumentNotValidException` → 400 `REQUISICAO_INVALIDA`.
- Enum inválido → `HttpMessageNotReadableException` → 400 `REQUISICAO_INVALIDA`.

### Teste `AcoesVilaControllerWebMvcTest`
- `@WebMvcTest(AcoesVilaController.class)` com `@Import(SecurityConfig, ErroApiHandler, ...)`.
- Serviços `@MockitoBean`.
- Cenários:
  - Anônimo → 401.
  - POST sem CSRF token → 403.
  - POST com token válido (mock) → serviço chamado.
  - Request body inválido (enum errado, quantidade 0, nível 6) → 400.
  - Serviço lança `RegraJogoException(FILA_OCUPADA)` → 422.
  - Serviço lança `RegraJogoException(TURNO_DESATUALIZADO)` → 409.
  - Mock `EstadoVila` retornado → 200 com `VilaDto` serializado.
