# Task 5.2 — Gerador de loot

**Índice:** [tasks.md](../tasks.md) · **Depende de:** [1.3](1.3-catalogo-estatico-jogo.md) [1.4](1.4-infra-relogio-aleatorio-erros.md) · **Paralela com:** —

## Objetivo
Implementar o gerador puro de loot que, dada uma vitória em um nível de masmorra, sorteia recursos, sementes e itens seguindo tabela determinística com injeção de aleatório.

## Contexto necessário

- [spec game-dungeon-loot — Recursos e sorteios](../specs/game-dungeon-loot/spec.md) — garantido 40N comida/50N madeira/50N pedra/20N ferro; rolagens `1 + ceil(N/2)`; faixas de sorteio 0–34 semente, 35–59 ferro, 60–99 item; nível do item `min(5, N + 0|1)`, origem MASMORRA
- [Catálogo — Cultivos e modelos](1.3-catalogo-estatico-jogo.md) — enum `Cultivo` com pesos MILHO 60/BATATA 30/ABOBORA_DOURADA 10 (liberadas por nível); modelos ESPADA/LANCA/ARCO/ARMADURA_COURO/ARMADURA_FERRO
- [Infraestrutura — Aleatorio](1.4-infra-relogio-aleatorio-erros.md) — injeção de `Aleatorio.proximoInt(limite)` → 0..limite−1

## Notas de implementação

### Estrutura
- `Loot(recursos: Map<TipoRecurso, long>, sementes: Map<Cultivo, int>, itens: List<Item>)` — record com recursos em milésimos (antes de exibir, dividir por 1000).
- `GeradorLoot` — classe com método `gerar(nivelMasmorra: int, aleatorio: Aleatorio): Loot`.

### Algoritmo de loot
```
Garantido: comida += 40*N*1000, madeira += 50*N*1000, pedra += 50*N*1000, ferro += 20*N*1000
Rolagens: quantidade = 1 + ceil(N/2)  → N1: 2, N2: 2, N3: 3, N4: 3, N5: 4

para cada rolagem:
  d = aleatorio.proximoInt(100)  → 0..99
  se d em [0, 34]:
    semente: pesos = {MILHO: 60 (N≥1), BATATA: 30 (N≥2), ABOBORA_DOURADA: 10 (N≥4)}
            r = aleatorio.proximoInt(somaPesos)  → na ordem: MILHO, BATATA, ABOBORA_DOURADA
            +1 sementes[r]
  se d em [35, 59]:
    ferro extra: +30*N*1000 milésimos (ferro adicional)
  se d em [60, 99]:
    item: m = aleatorio.proximoInt(5)  → 0..4 ordem: ESPADA, LANCA, ARCO, ARMADURA_COURO, ARMADURA_FERRO
          nivel = min(5, N + proximoInt(2))  → 0 ou 1 aleatório
          cria Item(modelo=m, nivel, origem=MASMORRA, status=DISPONIVEL)
```

### Cultivos liberados por nível
- MILHO: N ≥ 1
- BATATA: N ≥ 2
- ABOBORA_DOURADA: N ≥ 4
- Cultivos não liberados têm peso 0 na rolagem.

### Teste com `AleatorioSequencia`
- `AleatorioSequencia` (implementação mock em `jogo/suporte/AleatorioSequencia.java`): classe que devolve valores predefinidos em sequência.
- Teste injeta sequências fixas e valida o loot gerado byte a byte.
- Exemplo: `[10, 0, 70, 0, 1]` → `proximoInt(100)` retorna 10 (semente), 0 (MILHO), 70 (item), 0 (ESPADA), 1 (nível +1) → total 1 MILHO semente, 1 ESPADA nível N+1.

## Critérios de aceite
- Compilação sem erros.
- Teste `GeradorLootTest` passa com: garantido correto (cálculo 40N × 1000 etc.), rolagens por nível (quantidade certa), sementes por nível (ABOBORA_DOURADA só N≥4), item nível (min 5, N+proximoInt(2)), sequências determinísticas validadas byte a byte.
- Loot puro, sem efeitos colaterais; método `gerar` não muta entrada.
