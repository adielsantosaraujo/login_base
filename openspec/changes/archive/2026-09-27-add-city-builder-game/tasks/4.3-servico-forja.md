# Task 4.3 — Serviço da forja

**Índice:** [tasks.md](../tasks.md) · **Depende de:** 3.2 · **Paralela com:** 4.1, 4.2, 4.4, 5.3, 6.1

## Objetivo
Criar o `ForjaService` que cria ordens de forja para itens (armas e armaduras) com modelo, nível (1–5) e quantidade (1–5). Debita recursos, cria uma ordem única (fila de 1), e na conclusão, entrega todos os itens `DISPONIVEL` com origem `FORJA`.

## Notas de implementação

**ForjaService** (`@Service`, `@Transactional`):
- `forjar(long usuarioId, ModeloItem modelo, int nivel, int quantidade): void`
  - Obtém vila com lock
  - Valida:
    1. Forja nível 0 → `REQUISITO_NAO_ATENDIDO`
    2. `nivel > forja.nivel` → `REQUISITO_NAO_ATENDIDO`
    3. `nivel < 1` ou `nivel > 5` ou `quantidade < 1` ou `quantidade > 5` → 400 `REQUISICAO_INVALIDA` (@Valid)
    4. Já existe ordem FORJA → `FILA_OCUPADA`
    5. Recursos insuficientes → `RECURSOS_INSUFICIENTES`
  - Calcula custo total: `custo(modelo, nivel) × quantidade`
  - Calcula tempo total: `ceil(tempoBase × nivel × quantidade / velocidade)` segundos
  - Debita recursos
  - Cria Ordem: `categoria=FORJA, alvo=modelo.nome(), nivel=nivel, quantidade=quantidade, iniciada_em=now, conclui_em=now+tempo`
  - Salva ordem

**Tempo total** (A.7):
- `tempoBase × nivel × quantidade / velocidade`, ceil
- Ex.: 2 ESPADAS nível 2 = `60 × 2 × 2 = 240s` com velocidade 1

**Aplicação** (em `AplicadorOrdens`):
- Para cada `i` de 1 a quantidade: cria Item com `modelo`, `nivel`, `origem=FORJA`, `status=DISPONIVEL`

**Testes** (`@DataJpaTest`, `@Import`):
- Validações (5 erros): forja 0, nível > forja.nivel, faixa inválida (400), fila ocupada, recursos insuficientes
- Custo correto (tabela A.7): 2 ESPADAS N2 = M80 F120
- Tempo correto: `ceil(60 × 2 × 2 / 1)` = 240s
- Entrega: após conclusão, 2 items criados com DISPONIVEL
- Velocidade: com `JOGO_VELOCIDADE=2`, tempo metade

## Critérios de aceite
- Valida nível 1–5, quantidade 1–5 (400 fora da faixa)
- Forja nível 0 → REQUISITO_NAO_ATENDIDO
- Nível do item > nível da forja → REQUISITO_NAO_ATENDIDO
- Fila de 1 por vila → FILA_OCUPADA
- Custo e tempo calculados corretamente
- Itens entregues com status DISPONIVEL, origem FORJA
