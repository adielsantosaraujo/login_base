## Notas de implementação

### Classes puras (sem JPA)
Todas as classes em `jogo.masmorra.combate` são records ou classes imutáveis (sem anotações JPA):
- `Posicao(x, y)` — record; métodos `distanciaManhattan(outro)`.
- `Lado(JOGADOR, INIMIGO)` — enum.
- `Combatente(id, lado, tipoOuUnidade, posicao, hp, hpMax, ataque, defesa, alcance, movimento, defendendo, moveu, agiu, vivo)` — record imutável; métodos `recebeDano(dano)` → novo combatente com HP reduzido.
- `AcaoCombate(tipo, combatenteId, x, y, alvoId, turno)` — record; `tipo` = enum `MOVER`, `ATACAR`, `DEFENDER`, `ENCERRAR_TURNO`, `RENDER`.
- `EstadoBatalha(combatentes, lado do jogador/inimigos, turno, turnoMaximo, mapa, estágio final, log, resultado)` — record imutável; métodos `atualizarCombatente`, `removerCombatente`, `encerrar` etc.
- `MotorCombate` — classe de métodos estáticos puros: `processar(estado, acao) → novoEstado`, `executarIA(estado) → novoEstado`, `terminou(estado) → boolean`, `resultado(estado) → VITORIA|DERROTA|NULO`.

### Validações de ação (422)
Cada método valida antes de processar; falha em `AcaoInvalidaException`:
- **Mover**: destino fora da grade, obstáculo, ocupado, não alcançável por BFS, combatente já agiu/moveu.
- **Atacar**: já agiu, alvo fora do alcance Manhattan, alvo não é inimigo ou está morto.
- **Defender**: já agiu.
- **Encerrar turno**: nenhuma validação (sempre permitido).
- **Render**: nenhuma validação.

### BFS (`Caminhos`)
Método `caminhoMaisCurto(inicio, fim, movimento, obstaculos, combatentes) → List<Posicao>` usando fila (BFS) de (posição, distância):
- Busca casas ortogonais (não diagonais) livres (sem obstáculo e sem combatente vivo).
- Retorna caminho de comprimento ≤ movimento; vazio se não alcançável.

### Dano e defesa
- Dano base = `ataque − defesaEfetiva`.
- `defesaEfetiva = defesa × 2` se o alvo está `defendendo`; senão `defesa`.
- Dano mínimo = 1 (max com 0 → 1).

### IA dos inimigos (determinística)
Executada em `ENCERRAR_TURNO`, na ordem I1..I5 (vivos apenas):
1. Alvo = combatente vivo do jogador com menor distância Manhattan; empate → menor HP → menor id (ordem lexicográfica `combatenteId`).
2. Se no alcance → ataca.
3. Senão → move para casa alcançável (BFS ≤ movimento, casas livres, incluindo ficar parado) que minimiza a distância Manhattan ao alvo; empate → menor `y` → menor `x`. Depois, se o alvo ficou no alcance, ataca.
4. Se todas as unidades do jogador morrem durante a IA → encerra com `DERROTA` imediatamente.

### Fim da batalha
- `VITORIA`: todos os inimigos mortos (após cada ataque do jogador).
- `DERROTA`: todas as unidades do jogador mortas, `RENDER`, ou fim do turno 30 com inimigos vivos.
- Log: uma linha por evento (`Turno 1 começou.`, `J3 moveu para (2,5).`, `J3 atacou I1 causando 7 dano.`, `I1 morreu.` etc.). O log é acumulado na batalha.
