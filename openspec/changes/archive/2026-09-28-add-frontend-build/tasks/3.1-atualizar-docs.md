## Notas de implementação

**docs/09-guia-desenvolvedor.md:**

Adicionar uma seção (ex.: §3 ou a existente relacionada a build) descrevendo:

1. **Como gerar o build de produção do frontend:**
   - Executar `make build_front`
   - Pré-requisito: Docker rodando
   - O que acontece: executa `python3 ./scripts/build_front.py`, que chama `docker compose run --rm --build frontend-build`, copia assets para `src/main/resources/static/app/`, template para `src/main/resources/templates/sistema/seguro/index.html`, gera `build.log`

2. **Artefatos gerados:**
   - `frontend/dist/` (temporário, descartado entre execuções)
   - `src/main/resources/static/app/` (versionado em `.gitignore`, cópia dos assets)
   - `src/main/resources/templates/sistema/seguro/index.html` (versionado em `.gitignore`, view da SPA)
   - `build.log` (log da execução, truncado a cada run)

3. **Workflow de desenvolvimento:**
   - Dev server: `make up` (frontend service com hot reload)
   - Build de produção: `make build_front` antes de `./mvnw package` ou `docker compose build app`

4. **Troubleshooting:**
   - Se `make build_front` falhar, revisar `build.log` e output do Docker
   - Se template não aparecer em testes, verificar `src/test/resources/templates/sistema/seguro/index.html`

**docs/10-implantacao-operacao.md:**

1. **§5 "Frontend (distribuição)":**
   - Descrever que o frontend agora é servido pelo backend em `/` e rotas da SPA
   - Mencionar que assets estão em `/app/**`
   - Notar que o build de produção é parte do pipeline (não é mais "sem servir SPA")

2. **§6 "Deployment" ou equivalente:**
   - **Clone limpo (primeira vez):**
     ```
     git clone ...
     cd login_base
     make build_front  # IMPORTANTE: gera frontend/dist e copia para backend
     ./mvnw package    # depois do build do frontend
     docker build -t login-base:latest .
     ```
   - **CI/CD:**
     - Executar `make build_front` antes de `./mvnw package` ou `docker compose build app`
     - Garantir que Docker está disponível (node_modules e build do Vite requerem container)

   - **Rollback:**
     - Reverter para commit anterior (desfaz docker-compose.yml, Makefile, script, etc.)
     - Deploy da versão anterior (serve placeholder "Seja bem vindo")

3. **Mudar a frase "Sem servir SPA em produção":**
   - De: "Sem servir SPA em produção" (Non-Goal da versão anterior)
   - Para: "O frontend Vue/Vite é servido pelo backend em `/` após build via `make build_front`"

## Notas adicionais

- Serviço Docker `frontend-build` com profile `build`, volume anônimo `/app/node_modules`, sem `VITE_PRIMEUI_LICENSE`

- Artefatos: `frontend/dist/` (temporário), `src/main/resources/static/app/` (versionado em `.gitignore`), `src/main/resources/templates/sistema/seguro/index.html` (versionado em `.gitignore`, agora gerado)
- Vite com `base: '/app/'` apenas no build
- Backend serve SPA em `/` e assets em `/app/**`
- Build é pré-requisito para `./mvnw package` em clone limpo
