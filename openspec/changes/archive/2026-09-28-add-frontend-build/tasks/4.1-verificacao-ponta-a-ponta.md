# Task 4.1 — Build ponta a ponta

**Índice:** [tasks.md](../tasks.md) · **Depende de:** 1.1, 1.2, 1.3, 2.1 · **Paralela com:** —

## Objetivo

Executar um build completo do frontend (do zero até o backend servindo a SPA), validar que os artefatos foram gerados corretamente, que não há alterações não-commitadas que deveriam estar ignoradas, e que todos os testes continuam passando.

## Contexto necessário

- [design.md — Risks / Trade-offs: Clone limpo sem `make build_front` → erro 500](../design.md#risks--trade-offs) — validar que o processo documentado funciona

- [spec frontend-app — Requirement: Build de produção integrado ao backend](../specs/frontend-app/spec.md#requirement-build-de-produção-integrado-ao-backend) — Scenarios: build bem-sucedido, build com erro, log

- Tasks paralelas (1.1, 1.2, 1.3, 2.1) completas

## Arquivos a criar/alterar

Nenhum. Esta task apenas valida a integração das tarefas anteriores.

## Notas de implementação

**Sequência de validação:**

1. **Limpar artefatos de build anteriores (simular clone limpo):**
   ```bash
   rm -rf frontend/dist/
   rm -rf src/main/resources/static/app/
   rm -f src/main/resources/templates/sistema/seguro/index.html (se existir versão gerada)
   rm -f build.log
   ```

2. **Executar build do frontend:**
   ```bash
   make build_front
   ```
   - Deve completar sem erro (exit code 0)
   - Deve gerar `build.log` com mensagens de sucesso

3. **Validar artefatos gerados:**
   ```bash
   # Template gerado deve existir e conter /app/assets/
   test -f src/main/resources/templates/sistema/seguro/index.html
   grep -q '/app/assets/' src/main/resources/templates/sistema/seguro/index.html
   
   # Assets devem estar em static/app/
   test -d src/main/resources/static/app/
   ls src/main/resources/static/app/ | grep -q .
   
   # Build log deve existir
   test -f build.log
   ```

4. **Confirmar que artefatos estão no .gitignore:**
   ```bash
   git check-ignore build.log src/main/resources/static/app/ src/main/resources/templates/sistema/seguro/index.html
   ```
   - Nenhum dos caminhos deve aparecer em `git status`

5. **Rodar testes completos:**
   ```bash
   ./mvnw test
   ```
   - Todos os testes devem passar (incluindo os novos de rotas SPA)

6. **Verificar git status (não deve mostrar gerados):**
   ```bash
   git status
   ```
   - `build.log` não deve aparecer
   - `src/main/resources/static/app/` não deve aparecer
   - `src/main/resources/templates/sistema/seguro/index.html` não deve aparecer
   - (Podem aparecer outras alterações em código fonte, que é OK)

## Critérios de aceite

- `make build_front` executa com sucesso e exit code 0
- `src/main/resources/templates/sistema/seguro/index.html` gerado contém referências a `/app/assets/...`
- `src/main/resources/static/app/` contém todos os assets do build (JS, CSS, imagens, etc.)
- `build.log` foi gerado e contém histórico do build
- `git status` não lista os 3 artefatos como modificados/não-rastreados
- `./mvnw test` passa completamente
- Não há estado inconsistente (ex.: template sem assets, assets sem template)

## Verificação

```bash
# 1. Limpar estado anterior (simulador clone limpo)
rm -rf frontend/dist/
rm -rf src/main/resources/static/app/
rm -f src/main/resources/templates/sistema/seguro/index.html
rm -f build.log

# 2. Executar build
echo "=== Executando make build_front ===" 
make build_front
BUILD_RC=$?
echo "Build exit code: $BUILD_RC"
test $BUILD_RC -eq 0 || { echo "Build falhou!"; exit 1; }

# 3. Validar artefatos
echo "=== Validando artefatos ==="
test -f src/main/resources/templates/sistema/seguro/index.html && echo "✓ Template gerado"
test -d src/main/resources/static/app/ && echo "✓ Diretório assets existe"
test -f build.log && echo "✓ build.log gerado"

# Verificar conteúdo do template
grep '/app/assets/' src/main/resources/templates/sistema/seguro/index.html && echo "✓ Template referencia /app/assets/"

# 4. Confirmar gitignore
echo "=== Confirmando .gitignore ===" 
git check-ignore build.log && echo "✓ build.log ignorado"
git check-ignore src/main/resources/static/app/ && echo "✓ static/app/ ignorado"
git check-ignore src/main/resources/templates/sistema/seguro/index.html && echo "✓ template ignorado"

# 5. Validar git status
echo "=== Validando git status ===" 
git status --porcelain | grep -E 'build\.log|static/app/|templates/sistema/seguro/index\.html' && { echo "✗ Artefatos aparecem em git status"; exit 1; }
echo "✓ Nenhum artefato em git status"

# 6. Rodar testes
echo "=== Executando testes ===" 
./mvnw test
TEST_RC=$?
test $TEST_RC -eq 0 && echo "✓ Todos os testes passaram" || { echo "✗ Testes falharam"; exit 1; }

# 7. Resumo
echo "=== Verificação concluída com sucesso ===" 
```
