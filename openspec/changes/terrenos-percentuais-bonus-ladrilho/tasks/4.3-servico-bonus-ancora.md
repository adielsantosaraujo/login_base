# Task 4.3 — Serviço de bônus por âncora

**Índice:** [tasks.md](../tasks.md) · **Depende de:** [2.1](2.1-migration-v18-entidades.md), [3.2](3.2-catalogo-terreno-quartel.md) · **Paralela com:** [4.1](4.1-mapa-detalhe-anexacao-api.md), [4.2](4.2-marcacao-por-terreno.md)

## Objetivo
Criar o serviço que calcula o bônus de um prédio pelo seu ladrilho-âncora e o bônus de grupo (Comércio, Desenvolvimento, Militar) pela média das âncoras, para os consumidores da onda 5.

## Contexto necessário
- [design.md — D9. Bônus do prédio pela âncora](../design.md#d9-bônus-do-prédio-pela-âncora) — `bonusDoPredio`, `fatorDoPredio` (copiar)
  > Terreno do prédio vazio → 0; âncora = `findByRegiaoIdAndXAndY(regiao.id, c.getX(), c.getY())`; terreno da âncora = terreno do prédio → `bonus_total`; senão 0 (região ou ladrilho ausentes também dão 0). `fatorDoPredio` = 1 + bonus/100, escala 2.
- [design.md — D10. Bônus de grupo pela média](../design.md#d10-bônus-de-grupo-pela-média) — `GrupoBonusVila`, `media`, `fator` (copiar)
  > Estado ATIVA ou EM_UPGRADE; só âncoras no terreno do grupo; prédio no terreno certo com 0 entra com 0; média escala 2 HALF_UP; sem nenhum → 0; `fator` = 1 + media/100, escala 4 HALF_UP.
- [spec jogo-bonus-terreno — Requirement: Bônus do prédio pela âncora](../specs/jogo-bonus-terreno/spec.md#requirement-bônus-do-prédio-pela-âncora)
- [spec jogo-bonus-terreno — Requirement: Bônus de grupo pela média das âncoras](../specs/jogo-bonus-terreno/spec.md#requirement-bônus-de-grupo-pela-média-das-âncoras)

## Notas de implementação
- `GrupoBonusVila { COMERCIO(TipoTerreno.COMERCIO, MERCADO, ESTALAGEM), DESENVOLVIMENTO(TipoTerreno.DESENVOLVIMENTO, CASA), MILITAR(TipoTerreno.MILITAR, QUARTEL) }` com `terreno()` e `Set<TipoConstrucao> tipos()`.
- `BonusTerrenoService` (`@Service`, `@Transactional(readOnly = true)` nos métodos): `int bonusDoPredio(Long vilaId, Construcao c)`, `BigDecimal fatorDoPredio(Long vilaId, Construcao c)`, `BigDecimal media(Long vilaId, GrupoBonusVila g)`, `BigDecimal fator(Long vilaId, GrupoBonusVila g)`.
- `media`: `construcaoRepository.findByVilaId(vilaId)` filtrando tipo e estado; agrupar por `regiaoIndice`; carregar a região (`findByVilaIdAndIndice`) e os ladrilhos da região uma vez (`findByRegiaoIdOrderByYAscXAsc` → mapa `x,y`); considerar só âncoras com terreno do grupo.
- Teste de integração (montar vila, regiões e ladrilhos à mão; ladrilhos só nas âncoras usadas): os 5 cenários do spec de grupo; prédio EM_OBRA não entra; prédio no terreno certo com total 0 entra; `bonusDoPredio` com âncora certa (80 → fator 1,80), errada (0 → 1,00), prédio sem terreno (Armazém → 0) e ladrilho ausente (0); `fator` para média 45,50 = 1,4550.
