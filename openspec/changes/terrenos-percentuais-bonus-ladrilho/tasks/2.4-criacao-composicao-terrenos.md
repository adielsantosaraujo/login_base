## Notas de implementação
- `regioes.ts`: `RegiaoPrevia { indice: number; tipo: TipoRegiao; terrenos: TerrenoDaRegiao[] }` (import de tipo de `./terrenos`); remover `totaisBonus` (e seus testes); manter os demais exports de bônus intactos.
- `ListaTerrenos.vue`: props `itens: { terreno: TipoTerreno; valor: number }[]`, `maximo: number`, `sufixo?: string` (padrão `''`), `espessura?: 'fina' | 'normal'` (padrão `fina`); cada `li` com `data-testid="terreno-<TERRENO>"`, chip com a sigla (fundo `COR_TERRENO`, texto `--vl-accent-ink`), rótulo, `BarraValor` (`components/vilarejo/BarraValor.vue`) e valor com sufixo.
- `RegiaoTile.vue` e `RegiaoFoco.vue`: `ListaTerrenos` com `ordenarTerrenos(regiao.terrenos)` → `{ terreno, valor: percentual }`, `maximo` 100, sufixo `%`; `aria-label` do tile: `Região NN · <Tipo> · ` + `composicaoTexto(regiao.terrenos)`.
- `SelecaoPainel.vue`: prop `totais: Record<TipoTerreno, number>`; seção `aria-label="Ladrilhos por terreno"` com título "Ladrilhos por terreno" e subtítulo "soma das regiões escolhidas"; itens só com total > 0, decrescentes; `maximo = Math.max(100, maior total)`; sem itens: `<p data-testid="ladrilhos-vazio">Selecione regiões para ver os ladrilhos</p>`.
- `useVila.ts`: `totaisLadrilhos = computed(() => totaisLadrilhos(selecionadas, regioes da prévia))` no lugar de `totaisBonus` (expor com o nome `totaisLadrilhos`); `CriacaoVila.vue` passa `:totais="totaisLadrilhos"`.
- Specs: fixtures de prévia com `terrenos` no lugar de `bonus`; casos novos do spec (rótulo acessível do tile; painel com o exemplo de 3 regiões; painel vazio).
- Não usar cor direta nos estilos; só tokens.
