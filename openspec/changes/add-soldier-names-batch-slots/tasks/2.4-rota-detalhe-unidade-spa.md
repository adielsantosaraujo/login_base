# Task 2.4 — Rota detalhe unidade na SPA

## Objetivo

Adicionar a rota `/quartel/unidades/:id` ao `PaginaController` para servir a tela de detalhe da unidade (view SPA), permitindo que o frontend navegue a partir da lista de unidades no quartel.

## Notas de implementação

**PaginaController.java:**

Acrescentar `/quartel/unidades/{id}` ao `@GetMapping` existente que mapeia as rotas da SPA:

```java
@GetMapping({"/", "/quartel", "/quartel/unidades/{id}"})
public String sistema(Model model) {
  // Retorna a view SPA (index.html) para todas as rotas do frontend
  return "sistema/seguro/index";
}
```

A rota `/quartel/unidades/{id}` segue o mesmo padrão das demais (nega ao anônimo, retorna a SPA autenticado).

**AutenticacaoWebMvcTest.java:**
- Adicionar teste: GET `/quartel/unidades/1` autenticado → 200 com view `sistema/seguro/index`
- Adicionar teste: GET `/quartel/unidades/1` anônimo → redirect `/login`

## Critérios de aceite

- Rota `/quartel/unidades/{id}` é acrescentada ao `@GetMapping` existente do `PaginaController`
- GET `/quartel/unidades/{id}` autenticado retorna 200 com view `sistema/seguro/index`
- GET `/quartel/unidades/{id}` anônimo redireciona para `/login` (302)
- Frontend pode navegar para a rota e chamar `GET /api/jogo/vila` para carregar dados
- Testes em `AutenticacaoWebMvcTest` cobrem autenticação e navegação
- `./mvnw test -Dtest=AutenticacaoWebMvcTest` passa

## Verificação

./mvnw test -Dtest=AutenticacaoWebMvcTest
