# Task 3.4 — Troca de equipamento no detalhe

**Índice:** [tasks.md](../tasks.md) · **Depende de:** [3.1](3.1-tipos-e-api-treino.md), [3.3](3.3-tela-detalhe-unidade.md) · **Paralela com:** [3.2](3.2-quartel-lote-quantidade.md)

## Objetivo
Adicionar à tela de detalhe da unidade o botão "Trocar" nos slots Arma e Armadura, com diálogo que lista os itens compatíveis `DISPONIVEL` e chama a API de troca.

## Contexto necessário
- [design.md — Decisão D9](../design.md#d9--frontend-com-máx-e-grid-de-9-slots) — comportamento do botão e do diálogo
  > Botão "Trocar" em Arma/Armadura (desabilitado com `EM_MASMORRA`); Dialog com itens de `vila.itens` `DISPONIVEL` — arma: `modelo === catalogo.tropas[tipo].armaExigida`; armadura: `categoria === 'ARMADURA'`; escolher chama `POST /api/jogo/unidades/{id}/equipamento`.
- [spec game-frontend — Requirement: Detalhe da unidade](../specs/game-frontend/spec.md#requirement-detalhe-da-unidade) — cenários "Trocar arma pelo detalhe" e "Troca bloqueada em masmorra"
  > Diálogo mostra modelo, nível, atributos e origem, ou "Nenhum item compatível disponível"; sucesso atualiza a tela com o `VilaDto` retornado; erros no Toast; dica "Indisponível durante a masmorra".
- [spec game-frontend — Requirement: Sem cálculo de regras no frontend](../specs/game-frontend/spec.md#requirement-sem-cálculo-de-regras-no-frontend) — o filtro é só UX; o backend valida
- [UnidadeDetalheView.vue](/frontend/src/views/UnidadeDetalheView.vue) — tela criada na 3.3
- [jogo.ts](/frontend/src/api/jogo.ts) — `jogoAPI.trocarEquipamento` (3.1) e `catalogo()`
- [QuartelView.vue](/frontend/src/views/QuartelView.vue) — padrão de Toast de erro e de uso do catálogo

## Arquivos a criar/alterar
- [UnidadeDetalheView.vue](/frontend/src/views/UnidadeDetalheView.vue)

## Notas de implementação
- PrimeVue: `Button`, `Dialog`, `DataTable` ou `Listbox`, `Toast`.
- Carregar o catálogo (`jogoAPI.catalogo()`) junto com a vila, para obter `armaExigida`.
- Depois do sucesso, substituir o estado da vila pelo `VilaDto` retornado e fechar o diálogo.
- Slots futuros sem botão.

## Critérios de aceite
- "Trocar" aparece só em Arma e Armadura; desabilitado com a unidade `EM_MASMORRA`
- Diálogo lista apenas itens compatíveis `DISPONIVEL`; estado vazio com a mensagem definida
- Troca bem-sucedida atualiza o slot e os atributos sem recarregar a página
- Erro 422 exibido no Toast com a mensagem do backend
- `cd frontend && npm run build` sem erros
