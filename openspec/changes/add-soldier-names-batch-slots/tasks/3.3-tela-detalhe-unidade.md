# Task 3.3 — Tela detalhe da unidade

**Índice:** [tasks.md](../tasks.md) · **Depende de:** 3.1 · **Paralela com:** —

## Objetivo

Criar o componente `UnidadeDetalheView.vue` que exibe nome, tipo, status e atributos de uma unidade, com grade de 9 slots de equipamento em cards (exibindo dados do item ou "Vazio"), navegação via rota `/quartel/unidades/{id}`, e atualizar router para incluir a nova rota.

## Notas de implementação

**UnidadeDetalheView.vue:**

Componente deve:

1. **Props/Route:**
   - Ler `route.params.id` (id da unidade)
   - Chamar `getVila()` para carregar dados da vila (inclui unidades)
   - Buscar a unidade pelo id

2. **Cabeçalho:**
   - Título: "Detalhe da unidade"
   - Nome de exibição: `unidade.nomeExibicao` (ex.: "Ana Silva" ou "Ana Silva (2)")
   - Tipo: exibir valor de `TipoTropa` (ex.: "Soldado")
   - Status: valor de `StatusUnidade` (ex.: "DISPONIVEL", "EM_MASMORRA")
   - Botão "Voltar" que navega para `/quartel`

3. **Seção de atributos:**
   - Grade com HP, Ataque, Defesa, Alcance, Movimento
   - Exibir valores de `UnidadeDto` (note: HP é um campo único `hp`, não `hpAtual`/`hpMaximo`)

4. **Grade de 9 slots:**
   - 9 cards em grid (ex.: 3 colunas, 3 linhas)
   - Cada card exibe:
     - Rótulo do slot (ex.: "Arma", "Capacete/chapéu")
     - Se item: modelo, nível, origem, atributos
     - Se vazio: texto "Vazio" centralizado
   - Deixar nos Cards Arma e Armadura um espaço para a ação "Trocar" (implementada na task 3.4)
   - Ordem dos slots: seguir enum `SlotEquipamento` (ARMA, ARMADURA, CABECA, ...)

5. **Tratamento de erros:**
   - Se unidade não encontrada: exibir "Unidade não encontrada" com botão "Voltar"
   - Se erro ao carregar vila: exibir mensagem de erro

6. **Estilo/Componentes:**
   - Usar PrimeVue (Card, Button, Divider, etc)
   - Consistência com layout do projeto

**router/index.ts:**

Adicionar rota:

```typescript
{
  path: '/quartel/unidades/:id',
  component: UnidadeDetalheView,
  meta: { requiresAuth: true }  // se o projeto usar meta
}
```

Ou conforme a estrutura existente de rotas.

**Dados e API:**

- Componente carrega dados via `getVila()` (já existente em jogo.ts)
- Extrai unidade da lista `vila.unidades` por id
- Acessa `unidade.equipamento` que é `Record<SlotEquipamento, ItemDto | null>`

## Critérios de aceite

- `UnidadeDetalheView.vue` exibe nome, tipo, status
- Cabeçalho com dados de identidade da unidade
- Seção de atributos (HP, ataque, defesa, alcance, movimento) com valores de `UnidadeDto`
- Grade de 9 slots em ordem de `SlotEquipamento`
- Slots ocupados exibem dados do item (modelo, nível, origem, atributos)
- Slots vazios exibem "Vazio"
- "Unidade não encontrada" com mensagem + botão "Voltar" se id inválido
- Botão "Voltar" navega para `/quartel`
- Rota `/quartel/unidades/{id}` mapeada no router com componente `UnidadeDetalheView`
- `cd frontend && npm run build` sem erros
- Componente compila sem erros
