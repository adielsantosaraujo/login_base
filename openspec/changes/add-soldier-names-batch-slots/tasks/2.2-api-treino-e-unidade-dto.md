## Notas de implementação

**VilaDto.java — adicionar UnidadeDto aninhada:**
```java
public record VilaDto(
  // ... campos existentes ...
  List<OrdemDto> ordensEmAndamento,
  List<UnidadeDto> unidades,
  
  public record UnidadeDto(
    long id,
    String nome,
    String sobrenome,
    int ordinalNome,
    String nomeExibicao,  // "Ana Silva" ou "Ana Silva (2)"
    TipoTropa tipo,
    String status,  // DISPONIVEL, EM_MASMORRA, etc
    // atributos finais
    int hp,  // saúde atual da unidade
    int ataque,
    int defesa,
    int alcance,
    int movimento,
    
    // 9 slots de equipamento
    LinkedHashMap<SlotEquipamento, ItemDto> equipamento  // chaves na ordem do enum
  ) {}
) {}
```

**JogoMapper.java:**
- Adicionar método: `UnidadeDto toUnidadeDto(Unidade unidade)`
- Preencher com `unidade.getOrdinalNome()` e `unidade.nomeExibicao()`
- Montar `equipamento` como `LinkedHashMap` com os 9 `SlotEquipamento`, reusando mapa de itens da vila já carregado (evitar N+1):
  ```java
  var slots = new LinkedHashMap<SlotEquipamento, ItemDto>();
  for (SlotEquipamento slot : SlotEquipamento.values()) {
    ItemDto item = null;
    if (slot == SlotEquipamento.ARMA && unidade.getArmaItemId() != null) {
      // Buscar no mapa já carregado (passado como parâmetro ou do contexto da vila)
      item = toItemDto(itemsMap.get(unidade.getArmaItemId()));
    } else if (slot == SlotEquipamento.ARMADURA && unidade.getArmaduraItemId() != null) {
      item = toItemDto(itemsMap.get(unidade.getArmaduraItemId()));
    }
    slots.put(slot, item);  // item é null se slot vazio
  }
  ```

## Critérios de aceite

- `UnidadeDto` inclui `nome`, `sobrenome`, `ordinalNome`, `nomeExibicao` com 9 slots
- `ordinalNome` e `nomeExibicao` formatado no backend
- `equipamento` é `LinkedHashMap<SlotEquipamento, ItemDto>` em ordem do enum
- Slots vazios contêm `null`; slots ocupados contêm dados do item
- Campo `hp` representa saúde atual; tipo é `TipoTropa`; status é string
- Mapeador reutiliza itens já carregados (sem N+1)
- Testes cobrem dados corretos em consulta de vila
- `./mvnw test -Dtest=VilaControllerWebMvcTest` passa
