## Notas de implementação

**Makefile:**

1. Adicionar marca de alvo phony (antes dos outros alvos):
   ```makefile
   .PHONY: build_front
   ```

2. Adicionar o alvo (preferencialmente após ou antes dos alvos relacionados a build/docker):
   ```makefile
   build_front: ## Gera o build do frontend e copia para o backend
       python3 ./scripts/build_front.py
   ```

3. Ajustar a linha de help (regex `%-10s` para `%-12s`):
   - Procurar a linha que gera o help dinâmico (ex.: `@grep -E '^[a-zA-Z_-]+:.*?## ' $(MAKEFILE_LIST) | sort | awk '...'`)
   - Mudar `%-10s` para `%-12s` para comportar nomes de alvo maiores (ex.: `build_front` tem 10 caracteres)

**Exemplo de linha de help ajustada:**
```makefile
@grep -E '^[a-zA-Z_-]+:.*?## ' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "%-12s %s\n", $$1, $$2}'
```

**.gitignore:**

Adicionar ao final do arquivo (ou em seção apropriada):
```
build.log
/src/main/resources/static/app/
/src/main/resources/templates/sistema/seguro/index.html
```

**Comando git rm --cached (executado após os passos acima):**

Após editar `.gitignore`, se o template `sistema/seguro/index.html` for uma versão antiga placer que já estava versionada, remover do índice:
```bash
git rm --cached src/main/resources/templates/sistema/seguro/index.html
```

(Mantém o arquivo no disco, mas deixa de versioná-lo.)

## Critérios de aceite

- Makefile contém o alvo `.PHONY: build_front` e a regra `build_front: ## ...`
- Help formatado com `%-12s` e alvo `build_front` aparece em `make help` ou `make e`
- `.gitignore` contém as 3 linhas: `build.log`, `/src/main/resources/static/app/`, `/src/main/resources/templates/sistema/seguro/index.html`
- `git check-ignore` valida os 3 caminhos (se existirem) como ignorados

## Verificação

```bash
# Confirmar alvo no Makefile
grep -A 1 "^build_front:" Makefile

# Executar make help e verificar que build_front aparece
make help | grep build_front

# Verificar que os caminhos estão no .gitignore
git check-ignore build.log
git check-ignore src/main/resources/static/app/
git check-ignore src/main/resources/templates/sistema/seguro/index.html
```
