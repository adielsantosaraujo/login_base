## Notas de implementação

### `UsuarioAtual` — utilitário
Classe com método estático `id(Authentication auth) → Long` que:
1. Extrai `auth.getName()` (e-mail).
2. Busca usuário via `UsuarioRepository.findByEmail()`.
3. Retorna `usuario.getId()`.
4. Injeta `UsuarioRepository` via construtor.

### `ErroDto` — record
```java
record ErroDto(String codigo, String mensagem) {}
```
- `codigo`: enum de `CodigoErro` (convertido para string).
- `mensagem`: texto em português do Brasil conforme o erro.

### `ErroApiHandler` — tratamento centralizado
`@RestControllerAdvice(basePackages = "com.example.loginbase.jogo.api")` com handlers:
1. `RegraJogoException` → **422** com `ErroDto(codigo, mensagem)`.
   - Exceção `TURNO_DESATUALIZADO` → **409** em vez de 422.
2. `ObjectOptimisticLockingFailureException` (lock otimista de `Batalha`) → **409** `CONFLITO`.
3. `RecursoNaoEncontradoException` → **404** `NAO_ENCONTRADO`.
4. `MethodArgumentNotValidException` (validação `@Valid`) → **400** `REQUISICAO_INVALIDA`.
5. `HttpMessageNotReadableException` (enum inválido, JSON mal formado) → **400**.
6. Fallback: **500** `ERRO_INTERNO`.

### `JogoMapper` — conversão EstadoVila → VilaDto + Catalogo → CatalogoDto
- `toVilaDto(EstadoVila, Clock)` — hydrata `VilaDto`:
  - `agora`: instant do clock.
  - `recursos`: `Map<String, Long>` (inteiros: `valor/1000`).
  - `capacidade`: capacidade do armazém (inteiro).
  - `producaoPorHora`: `Map<String, Integer>` calculado por `CalculadoraProducao`.
  - `predios`: lista com `tipo`, `nivel`, `nivelMaximo`, `proximoNivel` (só se nível < 5; traz custos com velocidade + `bloqueio`).
  - `ordens`: lista com todos os campos.
  - `canteiros`: lista com `posicao`, `cultivo`, `comidaPorHora`.
  - `sementes`: `Map<String, Integer>`.
  - `itens`: lista com `id`, modelo, categoria, nível, atributos (call `ModeloItem.atributos(nivel)`).
  - `unidades`: lista com tipo, HP, ataque, defesa, alcance, movimento, arma/armadura, status.
  - `capacidadeExercito`, `masmorraNivelLiberado`, `batalhaAtivaId`.
- `toCatalogoDto(JogoProperties)` — hydrata `CatalogoDto`:
  - `predios`: cada tipo com custos/tempos por nível (já com `JogoProperties.velocidade`).
  - `cultivos`, `modelos` (com atributos/receitas), `tropas`, `inimigos`, `masmorras` (com mapa/composição).

### `VilaController`
```java
@RestController
@RequestMapping("/api/jogo")
@Transactional
public class VilaController {
  @GetMapping("/vila")
  public ResponseEntity<VilaDto> consultarVila(Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    EstadoVila estado = vilaService.consultar(usuarioId);
    VilaDto dto = jogoMapper.toVilaDto(estado, clock);
    return ResponseEntity.ok(dto);
  }

  @GetMapping("/catalogo")
  public ResponseEntity<CatalogoDto> catalogo() {
    CatalogoDto dto = jogoMapper.toCatalogoDto(jogoProperties);
    return ResponseEntity.ok(dto);
  }
}
```
- Anônimo em `/api/jogo/**` recebe 401 (SecurityConfig em 1.1).
- DTOs com Jackson (`@JsonProperty` se necessário para renomear).

### Teste `VilaControllerWebMvcTest`
- `@WebMvcTest(VilaController.class)` com `@Import(SecurityConfig, ErroApiHandler, ...)`.
- Serviços `@MockitoBean`.
- Cenários:
  - Anônimo → 401.
  - Autenticado GET `/vila` → 200 com JSON válido.
  - GET `/catalogo` → 200.
  - `RegraJogoException` com `RECURSOS_INSUFICIENTES` → 422 com código/mensagem.
  - `RegraJogoException` com `TURNO_DESATUALIZADO` → 409.
  - `RecursoNaoEncontradoException` → 404.
  - Enum inválido → 400.
  - Mock `EstadoVila` e `CatalogoDto` com dados válidos.
