## Notas de implementação

**Recursos** (A.1):
- Enum `TipoRecurso`: COMIDA, MADEIRA, PEDRA, FERRO
- Capacidade = `500 × 2^(n-1)` por nível (N1–N5)
- Armazenados em milésimos (`long`, 1 unidade = 1000)

**Prédios** (A.3, tabela):
- Enum `TipoPredio` com custos base (record `Custo` com mapa recurso→quantidade)
- `custo(nivel)` = `round_half_up(base × 1.5^(n-1))`
- `tempoSegundos(nivel)` = `tempoBase × 2^(n-1)`
- Nível máximo 5, nível 0 = não construído
- Efeitos por nível: CENTRO_VILA (limita outros), ARMAZEM (capacidade), FAZENDA (canteiros), SERRARIA/PEDREIRA/MINA_FERRO (produção +taxas), FORJA (nível máximo item), QUARTEL (capacidade exército + libera tipos)

**Cultivos** (A.5):
- Enum `Cultivo`: TRIGO, MILHO, BATATA, ABOBORA_DOURADA
- Cada um com produção/h (20, 30, 45, 70)
- TRIGO não exige semente (infinita)

**Itens** (A.6, tabela):
- Record `ModeloItem` com categoria (ARMA, ARMADURA)
- Enum com ESPADA, LANCA, ARCO, ARMADURA_COURO, ARMADURA_FERRO
- `atributos(nivel)` → ataque/defesa/alcance calculados: ex. ESPADA = 6 + 2(L-1)

**Forja** (A.7, tabela):
- Cada modelo tem custo base (por L) e tempo base
- `custoTotal(nivel, quantidade)` = `custoBase × nivel × quantidade`
- `tempoTotal(nivel, quantidade)` = `ceil(tempoBase × nivel × quantidade / velocidade)`

**Tropas** (A.8, tabela):
- Enum `TipoTropa`: SOLDADO, ARQUEIRO, LANCEIRO
- Cada tipo com HP, defesa base, movimento, comida (ordem), tempo de treino
- Quartel mínimo (libera em N1/N2/N3)

**Inimigos** (A.9, tabela):
- Enum `TipoInimigo`: GOBLIN, ESQUELETO_ARQUEIRO, ORC, TROLL
- Cada um com HP, ataque, defesa, alcance, movimento

**Masmorras** (A.9):
- Record `MapaMasmorra`: grid 8×8, lista de obstáculos (posições x,y), spawns de inimigos (S1–S5) e posições iniciais do jogador
- `CatalogoMasmorras`: níveis 1–5 com composição (lista de tipos de inimigos em ordem)

## Critérios de aceite
- Enums/records compilam e carregam sem erro na inicialização
- Tabela A.3 (custos/tempos de prédios) validada: N1→M150 P150 · 120s, N2→M225 P225 · 240s
- Tabela A.6 (atributos) validada: ESPADA N1→ataque 6, N2→8, N3→10; ARCO →alcance 3
- Tabela A.7 (receitas) validada: ESPADA base M20 F30 · 60s
- Tabela A.8 (tropas) validada: SOLDADO →HP 30, defesa 1, movimento 3
- Tabela A.9 (inimigos) validada: TROLL →HP 70, ataque 13
- Mapa 8×8 com 8 obstáculos, 5 spawns de inimigos, 4 posições iniciais do jogador
- Composições: N1→3 GOBLIN, N5→TROLL+2 ORC+2 ESQUELETO_ARQUEIRO
- API `GET /api/jogo/catalogo` retorna JSON com todos os valores (task 6.1)
