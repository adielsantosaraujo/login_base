## Notas de implementação

### DTOs e serialização

#### `BatalhaDto` — snapshot do estado da batalha
```java
record BatalhaDto(
    long id,
    int masmorraNivel,
    String status,  // EM_ANDAMENTO, VITORIA, DERROTA
    int turno,
    int turnoMaximo,
    int largura, int altura,
    List<ObstaculoDto> obstaculos,
    List<CombatenteDto> combatentes,
    List<String> log,
    LootDto loot  // null em EM_ANDAMENTO
) {}

record ObstaculoDto(int x, int y) {}

record CombatenteDto(
    String id,  // J3, I1 etc.
    String lado,  // JOGADOR, INIMIGO
    Long unidadeId,  // null para inimigo
    String tipo,  // SOLDADO, GOBLIN etc.
    int x, int y,
    int hp, int hpMax,
    int ataque, int defesa, int alcance, int movimento,
    boolean defendendo, boolean moveu, boolean agiu, boolean vivo
) {}

record LootDto(
    Map<String, Long> recursos,  // inteiros
    Map<String, Integer> sementes,
    List<ItemDto> itens
) {}

record ItemDto(
    long id,
    String modelo,
    String categoria,
    int nivel,
    int ataque, int defesa, int alcance,
    String origem,  // MASMORRA
    String status
) {}
```

#### `IniciarBatalhaRequest`
```java
record IniciarBatalhaRequest(List<Long> unidadeIds) {}
```
- Validar: `unidadeIds` não nulo, não vazio, tamanho ≤ 4 → 400 se falhar.

#### `AcaoCombateRequest`
```java
record AcaoCombateRequest(
    String tipo,  // MOVER, ATACAR, DEFENDER, ENCERRAR_TURNO, RENDER
    String combatenteId,  // J3, I1 etc. — validar se presente
    Integer x,  // null se não mover
    Integer y,  // null se não mover
    String alvoId,  // null se não atacar
    int turno
) {}
```
- `tipo` enum inválido → 400.
- `turno` obrigatório; falta → 400.

### `JogoMapper` — extensão para DTOs de batalha
- `toBatalhaDto(Batalha)` — desserializa `EstadoBatalha` do JSON `estado`, monta `BatalhaDto`:
  - `id`, `masmorraNivel`, `status`, `turno` diretos.
  - `turnoMaximo` = 30.
  - Mapa: `largura` 8, `altura` 8, `obstaculos` do `MapaMasmorra`.
  - Combatentes: lista de `CombatenteDto` a partir de `EstadoBatalha.combatentes`.
  - Log: `Batalha.log.split("\n")` com filtro de linhas vazias.
  - Loot: desserializa `Batalha.loot` JSON se status = `VITORIA`, senão null; recursos em inteiros.
- `toBatalhaDto(BatalhaDto, Batalha)` — versão que aceita `EstadoBatalha` já desserializado (para otimizar teste).

### `MasmorraController`
```java
@RestController
@RequestMapping("/api/jogo")
@Transactional
public class MasmorraController {
  @PostMapping("/masmorras/{nivel}/batalhas")
  public ResponseEntity<BatalhaDto> iniciar(
      @PathVariable int nivel,
      @Valid @RequestBody IniciarBatalhaRequest req,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    Batalha batalha = masmorraService.iniciar(usuarioId, nivel, req.unidadeIds());
    BatalhaDto dto = jogoMapper.toBatalhaDto(batalha);
    return ResponseEntity.status(201).body(dto);
  }

  @GetMapping("/batalhas/{id}")
  public ResponseEntity<BatalhaDto> consultar(
      @PathVariable long id,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    Batalha batalha = masmorraService.consultar(usuarioId, id);
    BatalhaDto dto = jogoMapper.toBatalhaDto(batalha);
    return ResponseEntity.ok(dto);
  }

  @PostMapping("/batalhas/{id}/acoes")
  public ResponseEntity<BatalhaDto> agir(
      @PathVariable long id,
      @Valid @RequestBody AcaoCombateRequest req,
      Authentication auth) {
    long usuarioId = UsuarioAtual.id(auth);
    // Converter request para AcaoCombate (domain)
    AcaoCombate acao = new AcaoCombate(
        AcaoCombate.Tipo.valueOf(req.tipo()),
        req.combatenteId(),
        req.x(), req.y(), req.alvoId(),
        req.turno()
    );
    Batalha batalha = masmorraService.agir(usuarioId, id, acao);
    BatalhaDto dto = jogoMapper.toBatalhaDto(batalha);
    return ResponseEntity.ok(dto);
  }
}
```
- **201** em criação (POST `/masmorras/{nivel}/batalhas`).
- **200** em consulta (GET `/batalhas/{id}`) e ação (POST `/batalhas/{id}/acoes`).
- **401** anônimo, **403** sem CSRF, **400** request inválido, **409** turno desatualizado, **404** batalha não encontrada, **422** ação inválida.

### Validação de turno
- `AcaoCombateRequest.turno` obrigatório; falta → 400.
- Se turno != turno atual de `EstadoBatalha` → `RegraJogoException(TURNO_DESATUALIZADO)` levantada pelo motor → **409** no handler.

### Teste `MasmorraControllerWebMvcTest`
- `@WebMvcTest(MasmorraController.class)` com `@Import(SecurityConfig, ErroApiHandler, ...)`.
- Serviços `@MockitoBean`.
- Cenários:
  - POST iniciar 201 com `BatalhaDto` válido.
  - GET consultar 200.
  - POST ação 200 com estado atualizado.
  - POST ação com turno antigo → 409 `TURNO_DESATUALIZADO`.
  - GET/POST batalha inexistente ou de outro usuário → 404.
  - Anônimo → 401.
  - Request inválido (enum, lista vazia) → 400.
  - Mock `EstadoBatalha` e `Batalha` com dados válidos, JSON validado.
