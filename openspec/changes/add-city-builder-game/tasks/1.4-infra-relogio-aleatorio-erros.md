## Notas de implementação

**Exceções**:
- `RegraJogoException(CodigoErro codigo, String mensagem)` — lançada por serviços, mapeada em `ErroApiHandler` para 422 (exceção `TURNO_DESATUALIZADO` → 409)
- `CodigoErro`: enum com códigos: `RECURSOS_INSUFICIENTES`, `FILA_OCUPADA`, `NIVEL_MAXIMO`, `REQUISITO_NAO_ATENDIDO`, `CANTEIRO_INEXISTENTE`, `SEMENTE_INDISPONIVEL`, `ITEM_INDISPONIVEL`, `CAPACIDADE_EXERCITO`, `MASMORRA_BLOQUEADA`, `BATALHA_EM_ANDAMENTO`, `UNIDADE_INDISPONIVEL`, `ESQUADRAO_INVALIDO`, `ACAO_INVALIDA`, `BATALHA_ENCERRADA`, `TURNO_DESATUALIZADO`, `CONFLITO`, `NAO_ENCONTRADO`, `REQUISICAO_INVALIDA`
- `RecursoNaoEncontradoException extends RuntimeException` — mapeada para 404

**Configuração** (`JogoProperties`):
- `@ConfigurationProperties("app.jogo")`
- Campo `velocidade: int` com validação `@Min(1)` → rejeita 0 ou negativo na inicialização
- Teste: default 1, valor 0 falha na validação

**Beans** (`JogoConfig`):
- `@Bean Clock` → `Clock.systemUTC()`
- `@Bean Aleatorio` → `new AleatorioPadrao()`
- `AleatorioPadrao` implementa `Aleatorio` com `int proximoInt(int limite)` → `RandomGenerator.getDefault().nextInt(limite)`

**Suporte de teste**:
- `RelogioAjustavel extends Clock` — implementação mutável: `avancar(Duration)` avança o relógio
- `AleatorioSequencia` — recebe lista/varargs de inteiros, `proximoInt(limite)` retorna próximo valor da sequência (ignorando `limite` para simplicidade de teste)
- `JogoTestConfig` — `@TestConfiguration` que sobrescreve os beans `Clock` e `Aleatorio` com versões de teste

## Critérios de aceite
- `JogoProperties.velocidade` padrão = 1
- `JogoProperties.velocidade=0` falha na inicialização (validação `@Min(1)`)
- `Clock` é injetável e retorna tempo UTC atual
- `Aleatorio.proximoInt(limite)` retorna valor 0–limite-1
- `RelogioAjustavel.avancar(Duration)` muda o relógio para testes
- `AleatorioSequencia` retorna valores em sequência para testes determinísticos
- Exceções compilam e podem ser lançadas por serviços
- `application.properties` contém `app.jogo.velocidade=${JOGO_VELOCIDADE:1}`
