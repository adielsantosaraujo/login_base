# Malho

**Ferramenta:** Ferreiro · **Épico:** [ferramentas.md](ferramentas.md)

## Profissão

Ferreiro. Características ligadas: INT.

## Oficina

Ferraria (qualquer nível: N1, N2, N3).

## Receita por nível

| Nível | Receita |
|---|---|
| L1 | 2 Ferro |
| L5 | 10 Ferro |
| L10 | 20 Aço |

Obs.: Para L ≥ 6, todo "Ferro" vira "Aço" (seção 7.4).

## Bônus

- Bônus de PE: **+L PE de Ferreiro** enquanto a pessoa trabalha em Fundição ou Ferraria.
- Bônus intrínsecos: Ferreiro pode receber PROF, PROD, INT, FOR, VEL (seção 7.2).

## Exemplo de eficiência

**Ferreiro sem Malho:**
- PE base Ferreiro: 2; características INT 8 → +1 bônus.
- PE efetivo = 2 + 1 = 3.
- Eficiência = 0,5 + 0,1 × 3 = 0,8.

**Ferreiro com Malho L5:**
- PE base Ferreiro: 2; características INT 8 → +1 bônus; Malho L5 → +5.
- PE efetivo = 2 + 1 + 5 = 8.
- Eficiência = 0,5 + 0,1 × 8 = 1,3.
- Ganho: +0,5 de eficiência em Fundição e Ferraria.

## Contexto

- Ferramenta de trabalho para ferreiros qualificados.
- Aumenta a produção de Ferro, Aço e itens metálicos.
